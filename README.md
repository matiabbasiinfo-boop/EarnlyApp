# Earnly Android App

This project wraps the supplied Earnly HTML frontend in an Android WebView.

## Open in Android Studio
1. Download/extract this project.
2. Open the `earnly-project` folder in Android Studio.
3. Allow Gradle to sync and install any requested Android SDK components.
4. Run the `app` configuration on an Android device or emulator.
5. Build an APK from **Build > Build APK(s)**.

## HTML frontend
The original frontend is stored at:

`app/src/main/assets/index.html`

## Back button
The Android back button sends the user to the HTML Home page first. Pressing Back again exits the app.
